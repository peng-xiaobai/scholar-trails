# 按研究方向找代表学者

## 理解方向与双语检索

1. **理解输入。** 保留用户原话，用一句话说明研究对象和研究问题，再提取其中明确指定的方法、应用场景、地域和时间。区分决定主题的概念与可扩展的指标、场景。含义明确时直接查。术语有歧义时，先从相关论文判断通行用法。如果仍有两种解释且会明显改变结果，再问一个具体问题。
2. **给出关键词对照。** 按概念列出中文学术用语和英文通行术语。用论文题名、摘要或作者关键词验证不确定的译名、缩写和同义词。缩写有多义时与领域术语一起用。把用户未限定的细分对象、指标和技术留作补查词。
3. **运行中文和英文查询。** 中文查中文索引、期刊官网和机构库，英文查学术搜索、专业索引、出版商和会议论文集。同一概念的异写用 `OR`，不同必选概念用 `AND`。来源不支持布尔语法时拆成短查询。先查核心概念，再从代表论文的关键词、引用和重点刊会补查。年份、地域和文献类型优先用来源支持的筛选字段。记录实际使用的查询、来源、起止年和最后检索日期。
4. **合并与核验。** 按 DOI 去重，缺 DOI 时用题名、年份、来源和署名核对。根据原文题名、摘要或全文判定相关性。检查完整作者表，核实候选作者的中英文署名、同名与跨机构身份。交付时先给出一句方向理解、简短的中英文关键词对照和实际检索范围。学者姓名有可靠的中英文对照时一并列出。[多源检索和去重](workflow.md#8-多源检索与漏检排查) · [作者身份核对](../../academic-author-match/SKILL.md)

以「定量遥感中的植被覆盖度反演」为例，先将研究对象对照为「植被覆盖度 / fractional vegetation cover (FVC)」，将研究任务对照为「反演 / retrieval」或「估算 / estimation」。中文可用 `(植被覆盖度 OR 植被覆盖率) AND 遥感 AND (反演 OR 估算)`，英文可用 `("fractional vegetation cover" OR "fractional vegetation coverage") AND "remote sensing" AND (retrieval OR estimation)`。从题名和摘要核对研究是否用遥感数据估算植被覆盖度。

## 核对作者并排序

1. 默认统计近五个自然年（含当年）的期刊论文与正式会议论文，沿用用户指定的地域、时间和成果类型。复查高产候选及可能高占比的候选，从作者档案、公开书目或机构成果页获取同一统计范围内的成果，逐条对账，再按题名、DOI 和完整署名回查缺项。现任单位用官网或公开履历核验。

2. 按确认归属的方向成果数排序，默认展示至多 10 位至少有 2 项方向成果的学者。同篇对每位已核实的署名作者计一次。主名单之外，可再列至多 3 位拥有至少 3 项方向成果且同期方向占比不低于 50% 的学者。按占比、方向成果数依次排序。用户指定总人数时按指定人数交付。方向占比为「同期已核实方向成果数 ÷ 同期已核实全部同类成果数」。仅在作者的同期清单已对账且主题归类已核实时计算占比，覆盖不足时标明待核。单篇命中的学者在稀缺方向可提供为后续核查线索。
3. 给出代表学者、署名或任职单位、方向成果数、可核对的同期总量和占比，每位附 1–3 项代表成果及 DOI 或原始来源。说明覆盖缺口。成果数量衡量这一检索范围内的产出，引用、声誉或影响力需要各自的指标。

## 用脚本计算

以[成果证据表](../assets/research_outputs_template.csv)记录已核实的署名。每次运行先按用户的文献类型、地域等条件整理证据，保留同一范围内与方向无关的成果作为分母。增加两列：

- `topic_status` 使用 `matched`、`outside_topic` 或 `pending`。对同一成果使用同一主题判断，未知可留空。保留正式年份与去重后的记录键。预印本与正式版按[成果版本规则](research_outputs.md#成果版本与归属)对齐。
- `topic_evidence` 记录主题判断的依据，例如出版方摘要链接与对应的方法或研究对象。确认匹配的成果须有依据。

可选的 `bibliographies.csv` 使用 `person_id,source` 两列。只登记同期全部同类成果已核对且核验来源可追溯的作者。证据表只覆盖主题搜索命中时，占比留空。

```bash
python skills/academic-faction-finder/scripts/topic_scholars.py --input topic_evidence.csv \
  --from-year 2021 --to-year 2025 --bibliographies bibliographies.csv --out topic_scholars.csv
```

脚本默认统计论文。指定 `--result-type patent` 或 `--result-type software` 时各自独立统计具名发明人或可核实的自然人开发者与著作权人。用 `--limit` 和 `--focused-limit` 调整两组的人数。已确认归属但主题待核的成果计入已查到的同期总量，并单列待核数，占比暂留空。
