# 学缘寻踪｜作者身份核对

从姓名、单位或一条已知署名定位候选。用机构双语主页、同一 ORCID 或同篇成果的同一署名位置确认姓名对应。沿已核实的旧合作者、历史单位及公开履历回查跨机构连续性。相同拼音、单位译名相似或单个同名合作者用于发现候选。身份冲突时保留候选及待核署名。[双语核对](../academic-faction-finder/references/workflow.md#10-双语搜索与备用源) · [跨机构归并](../academic-faction-finder/references/workflow.md#9-跨机构检索与归并)

只给姓名时，按相同范围比较各候选已核实的去重论文数，列出单位、方向和证据。并列或覆盖缺口可能改变首位时，保留多个候选。[仅姓名检索](../academic-faction-finder/references/workflow.md#11-仅姓名检索)

交付身份判断、已核实的双语姓名和机构别名、支撑证据及待核项。涉及机构经历时逐机构记录，区分公开履历日期、署名观察年份和推断区间。[机构时间线](../academic-faction-finder/references/workflow.md#13-机构时间线)
