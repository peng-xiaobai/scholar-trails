# 学缘寻踪｜按研究方向找学者

收到方向或研究问题时，用一句话概括其含义，按概念给出中英文关键词对照，然后实际运行两种语言的查询。以相关论文的题名、摘要和关键词校正术语，合并去重后核实作者。[双语检索流程](../academic-faction-finder/references/topic_scholars.md#理解方向与双语检索)

默认用近五个自然年（含当年）的期刊和正式会议论文，沿用用户指定的年份、地域、成果类型或人数。按已核实的方向成果数排序，再用已对账的同期成果占比补充代表学者。交付时给出方向理解、中英文关键词和实际检索范围，以及姓名、可核实的单位、成果数、可核实的占比和代表作。若用户接着要求查看某人的合作团队，使用[合作网络入口](../academic-faction-finder/SKILL.md)。
